# Design

- **Design system**: Industry. A light paper ground (#f2f2f3), ink #1d1f20 and a single steel accent with its 100-900 ramp (`--color-steel-*`, `--color-neutral-*` in `packages/ui/src/theme.css`). Cards, figures and the primary button are drawn as blueprint objects: square, hairline-framed, with "+" registration marks at the corners (the `blueprint` utility). Corners are square everywhere (Tailwind's radius scale is set to 0); dots stay round.
- **Palette**: the semantic tokens (`bg-surface`, `text-muted`, `bg-accent`, `border-field`, `text-success`, `text-danger`, ...) switch between light and dark with `light-dark()`. Two departures from Industry, both for contrast: its base steel (#5980a6) is 3.7:1 on the ground, so the primary fill and accent text use the 700 step (#416180, 5.8:1), and muted text the neutral 700 (#5d5d60) instead of 55% ink; input borders use the neutral 600 for 3:1. Industry has no dark mode; ours is derived (the deep steel #1d2d3d as ground, paper text, the 400 step as accent). The scheme is mono, so "done" also reads in steel; danger and warning use Tailwind's red and amber stops.
- `node scripts/contrast.ts` checks every token pair (4.5:1 for text, 3:1 for icons and input borders) in both modes and fails if one drops below.
- **Fonts**: Barlow Condensed for headings and buttons over Barlow for text, bundled through `@fontsource/barlow-condensed` and `@fontsource/barlow` so they work offline (Industry's stylesheet loads them from Google Fonts; Ream doesn't). Numbers use tabular figures. Text watermarks on images (Watermark image) are drawn in Barlow.
- **Icons**: Lucide's shapes at stroke 1.5, copied into `packages/ui/src/Icon.tsx` (ISC licence, no dependency). Whiteout, highlight and redact have no Lucide match and are drawn for Ream.
- **Logo**: one sheet cut on a diagonal and slid apart (split and merge). `Logo` in `packages/ui` follows the theme; `apps/web/public/favicon.svg` (in the steel colours) is the static version; `apps/web/icons/icon.svg` (the mark on the steel accent, square) is the source of the app icons.
- **Pages**: `/` is the landing page, `/tools/` the tools home, `/tools/pdf/` and `/tools/image/` the categories, `/tool/<id>/` a tool. Every page has its own address, title and description, so search engines and link previews can tell them apart.
- Not done: page thumbnails strip in the tool page (waits for M3 tools whose output keeps one page per input page), command palette. The design's network monitor, recent-files list, save-to folder and "Show in folder" were left out: Ream has none of them.
